# Company Website

قالب بداية لموقع شركة باستخدام HTML وCSS وJavaScript، جاهز للتعديل والنشر عبر GitHub Pages.

## هيكل الملفات
- `index.html`: الصفحة الرئيسية.
- `css/style.css`: تنسيقات وتصميم الموقع.
- `js/script.js`: أكواد JavaScript.
- `images/`: ضعي صور الموقع هنا.
- `fonts/`: ضعي ملفات الخطوط هنا.

## إضافة الصور
ارفعي الصور داخل مجلد `images`، ثم استدعيها في HTML مثل:
`<img src="images/company-logo.png" alt="شعار الشركة">`

## النشر
من إعدادات المستودع اختاري Settings ثم Pages، وبعدها Deploy from a branch، والفرع `main` والمجلد `/ (root)`.
